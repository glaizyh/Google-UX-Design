## 1. Design Approaches & Frameworks

### User-Centered Design Framework

- Puts the user front and center to reduce designer bias and solve real user problems.
- **Core Philosophy**: "Focus on the user and all else will follow."

**4-Step Process**

1. **Understand**: Research how the user experiences the product or similar products.
2. **Specify**: Narrow down the most important end-user problem based on research.
3. **Design**: Brainstorm and generate visual/functional product solutions.
4. **Evaluate**: Test designs against end-user needs with real people.

- **Iteration**: Doing something again by building on previous versions and making tweaks.

### Evolution of Inclusive Frameworks

| Framework | Description |
| --- | --- |
| **Universal Design** | A "one-size-fits-all" approach that aims to create one product for the widest range of users and situations. Often loses effectiveness because one size rarely fits everyone. |
| **Inclusive Design** | Focuses on finding multiple solutions to meet different personal needs (ability, race, age, gender, economic status). |
| **Equity-Focused Design** | Takes inclusive design a step further by specifically building products for groups that have been historically underrepresented, ignored, or excluded. |

**Inclusive Design**
- Philosophy: **"Solve for one, extend to many."** Solving for one group creates benefits that extend to others.
- Assumes there is no "normal" or average user.

**Equity-Focused Design**
- **Equality vs. Equity**: *Equality* gives everyone the exact same support/resources. *Equity* provides different levels of support tailored to individual needs to achieve fair outcomes.

## 2. Accessibility & Assistive Technologies

- **Accessibility**: Designing products, devices, services, or environments specifically for people with disabilities.
- **Assistive Technology (AT)**: Any product, equipment, or system that enhances learning, working, and daily living for people with disabilities.

### Common Assistive Technologies & Tools

| Tool | Description |
| --- | --- |
| **Color Modification** | High-contrast modes or dark mode to make text easier to see, reducing eye strain or glare |
| **Voice Control & Switch Devices** | Enables hands-free navigation and replaces physical keyboard/mouse input for users with limited motor dexterity |
| **Screen Readers** | Software that reads on-screen text, interactive button names, and hidden descriptions out loud for low-vision users |
| **Alternative Text (Alt Text)** | Text descriptions for meaningful images that assist visually impaired users or display context when low bandwidth prevents images from loading |
| **Speech-to-Text** | Converts spoken words into text automatically for hands-free typing |
| **Live Captions / Transcribe Tools** | Real-time text output for audio (e.g., Google Live Transcribe, InnoCaption); essential for deaf/hard-of-hearing users |

> **Best Practice**: Include edge cases and users with different abilities right from the start of the product development process, rather than as an add-on.

## 3. Equitable Design Applications (Race & Gender)

- **Design Considerations**: Ensure products treat all races, genders, and backgrounds fairly and inclusively.

### Form & Data Collection

- Re-evaluate whether asking for sensitive data (e.g., gender identity on job forms) is necessary.
- Provide diverse options beyond standard binary choices (e.g., male, female, gender nonconforming, nonbinary, open text field).

### Testing & Image Representation

- Test voice recognition and audio tools with diverse pitches, accents, and voice types to prevent system failure.
- Use inclusive visual imagery, avatars, illustrations, and icons that represent varied ages, races, and genders.

## 4. Designing Across Platforms (Mobile vs. Desktop)

### User Behaviors

| User Type | Behavior |
| --- | --- |
| **Mobile Users** | Goal-oriented, focused on single tasks, shorter sessions (avg. 72 seconds), navigate via tap/swipe gestures |
| **Desktop Users** | Longer engagement sessions (avg. 150 seconds) |
| **Next Billion Users** | New online users primarily access the internet using mobile devices, making mobile optimization essential |

### Responsive Web Design

- Allows layout and content to adapt automatically based on the user's screen size (e.g., collapsing multi-column desktop layouts into single-column mobile views).

### Mobile Design Best Practices

1. **Call to Action (CTA)**: Place key action buttons front and center.
2. **Simplified Navigation**: Keep menus short and highlight only core features.
3. **Familiar Gestures**: Leverage intuitive gestures like tapping and swiping.
4. **Dual Orientations**: Design smoothly for both vertical (portrait) and horizontal (landscape) views.
5. **Reduce Clutter**: Maintain clean visuals suited to small screen dimensions.
6. **Connectivity Constraints**: Account for varying hardware capabilities ($50 vs $500 phones) and slower internet load speeds.
